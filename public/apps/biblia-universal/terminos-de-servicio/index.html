Introducción

Estos Términos de Servicio regulan el uso de Biblia Universal (“la aplicación”). Al descargar, acceder o usar la aplicación, aceptas estos Términos. Si no estás de acuerdo, no debes usar la aplicación.

1. Descripción del servicio

Biblia Universal ofrece herramientas de lectura bíblica, búsqueda de versículos, planes de lectura, devocionales, oraciones, notas, recordatorios, comentarios, “me gusta” y compartidos en Versículo Diario, “amén” en el diálogo de oración, contenido visual y funciones relacionadas con la vida espiritual del usuario.

Algunas funciones pueden requerir conexión a internet, inicio de sesión con Google, Google Drive, Firebase, GitHub, Google Play Billing, servicios de publicidad o proveedores de donación.

2. Cuenta de usuario

La aplicación puede permitir iniciar sesión con Google. El usuario es responsable de:

  • Mantener segura su cuenta de Google.
  • Usar información verdadera y autorizada.
  • No permitir que terceros usen su cuenta para infringir estos Términos.

Podemos limitar o suspender funciones si detectamos abuso, fraude, spam, actividad automatizada, intentos de manipulación de datos o incumplimiento de estos Términos.

3. Uso permitido

Puedes usar la aplicación para fines personales, espirituales, educativos y devocionales.

No está permitido:

  • Usar la aplicación para actividades ilegales.
  • Publicar comentarios ofensivos, discriminatorios, amenazantes, sexuales, violentos, difamatorios o que vulneren derechos de terceros.
  • Publicar información privada de otras personas sin autorización.
  • Manipular contadores, “me gusta”, “amén”, compartidos, comentarios o sistemas de seguridad.
  • Intentar acceder a información de otros usuarios.
  • Copiar, modificar, distribuir o explotar comercialmente partes de la aplicación sin autorización.
  • Realizar ingeniería inversa, interferir con servidores o evadir controles de seguridad.

4. Contenido del usuario

El usuario puede crear notas, oraciones, comentarios, acciones sociales como “me gusta”, compartidos, “amén” u otro contenido dentro de la aplicación.

El usuario conserva la responsabilidad sobre el contenido que crea o publica. Al publicar comentarios visibles para otros usuarios, otorgas a la aplicación una licencia limitada para mostrar, almacenar, transmitir y moderar ese contenido dentro del servicio.

Podemos eliminar comentarios o contenido que incumpla estos Términos, afecte a otros usuarios, exponga datos sensibles o perjudique el funcionamiento de la aplicación.

5. Datos personales y privacidad

El tratamiento de datos personales se explica en la Política de Privacidad de Biblia Universal. Al usar la aplicación, aceptas que tus datos se traten conforme a esa Política.

6. Google Drive y sincronización

Las notas, versículos guardados, capítulos leídos y oraciones pueden guardarse en Google Drive de la cuenta del usuario cuando la función esté disponible o habilitada. El usuario es responsable de conservar acceso a su cuenta de Google.

La aplicación no garantiza recuperación de datos si el usuario elimina archivos de Drive, revoca permisos, pierde acceso a su cuenta o borra datos de la aplicación sin respaldo.

7. Planes y contenido remoto

Los planes bíblicos pueden leerse desde GitHub u otros servidores autorizados. El contenido puede actualizarse, cambiar o dejar de estar disponible por razones técnicas, editoriales o de mantenimiento.

La aplicación puede guardar localmente una copia del contenido leído desde GitHub para mejorar el rendimiento, permitir la consulta sin conexión o mantener disponible el contenido previamente cargado. Esa copia local puede sincronizarse o actualizarse cuando existan ediciones, cambios o nuevas versiones en el repositorio.

GitHub se utiliza para alojar contenido público de la aplicación, como planes bíblicos, archivos JSON o recursos relacionados. No debe usarse como almacenamiento de notas personales, oraciones privadas, versículos guardados ni progreso personal del usuario.

8. Suscripción, donaciones y anuncios

La aplicación puede mostrar anuncios mediante Google AdMob y/o plataformas de mediación publicitaria compatibles.

La aplicación puede ofrecer una suscripción mediante Google Play Billing, por ejemplo para eliminar anuncios u obtener beneficios premium. La suscripción se procesa y se administra mediante Google Play. Cancelaciones, renovaciones, reembolsos y gestión de la suscripción se rigen por las políticas de Google Play.

Biblia Universal no ofrece compras únicas dentro de la aplicación. La función de pago disponible, cuando corresponda, es la suscripción.

La aplicación también puede incluir una opción de donación voluntaria para apoyar el mantenimiento, desarrollo y continuidad del proyecto. Las donaciones son voluntarias y, salvo que se indique expresamente lo contrario, no constituyen compra de funciones digitales ni reemplazan la suscripción.

La disponibilidad de beneficios premium puede depender del estado de la suscripción, conexión a internet, cuenta de Google Play y validación técnica.

9. Recordatorios y notificaciones

La aplicación puede permitir configurar recordatorios y notificaciones. El usuario controla si concede permisos de notificación o alarmas exactas. El funcionamiento puede variar según la versión de Android, ahorro de batería, configuraciones del dispositivo o restricciones del fabricante.

10. Disponibilidad y cambios

Podemos modificar, suspender o retirar funciones de la aplicación por mantenimiento, mejoras, seguridad, cambios legales, decisiones de plataforma o razones técnicas.

No garantizamos que la aplicación esté libre de errores, interrupciones o incompatibilidades en todos los dispositivos.

11. Propiedad intelectual

La aplicación, su diseño, código, nombre, iconos, estructura, elementos visuales y funciones pertenecen a sus respectivos titulares. El contenido bíblico, imágenes, fuentes, librerías o servicios de terceros pueden estar sujetos a sus propias licencias.

El uso de la aplicación no otorga derechos de propiedad sobre el software ni sobre marcas o elementos protegidos.

12. Aviso espiritual y de contenido

La aplicación proporciona contenido bíblico, devocional y espiritual con fines de lectura, reflexión y crecimiento personal. No reemplaza asesoramiento profesional, médico, psicológico, legal, financiero ni pastoral individualizado.

13. Limitación de responsabilidad

En la medida permitida por la ley, Biblia Universal y sus responsables no serán responsables por daños indirectos, pérdida de datos, interrupciones, errores, decisiones tomadas por el usuario con base en el contenido, fallos de terceros, pérdida de acceso a cuentas externas o problemas derivados del uso incorrecto de la aplicación.

14. Terminación

Puedes dejar de usar la aplicación en cualquier momento. También puedes solicitar eliminación de cuenta y datos conforme al documento correspondiente.

Podemos limitar o terminar el acceso a funciones si existe incumplimiento de estos Términos o riesgo para otros usuarios, la seguridad o el servicio.

15. Cambios en estos Términos

Podemos actualizar estos Términos cuando cambien funciones, leyes, proveedores o prácticas de la aplicación. La fecha de última actualización indicará la versión vigente.
